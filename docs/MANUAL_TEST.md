# Manual test

What to check by hand before a demo or a hand-over, one row per acceptance criterion from the deck, plus the things no automated test covers. The "Automated" column names the test that checks the same thing, so a failing row here should also fail there.

**Before you start:** `npm run reset-demo`, then `npm run dev` and open http://localhost:3000. The simulated time is Monday 16 November 2026, 09:00 (Singapore). Switch persona with "Switch persona" at the top right. Run the rows in the order given: a few later rows use what an earlier row did (noted in the steps). `npm run reset-demo` puts everything back.

## Only by hand

| # | What | Steps | Expected result | Automated |
|---|---|---|---|---|
| M1 | Highlights sit on the right words | Open three different PDFs (a layout A PO, a layout B PO, a proof of payment) and click several fields. | Each highlight box covers the value it names, on the right page. | manual only |
